# Articulated Speaking Practice Library

Free articulation training and public speaking exercises for adults who want to express ideas clearly. The library includes 30 original speaking prompts, a practice timer, and a seven-day plan for meetings, interview answers, presentations, and everyday conversations.

**[Open the free prompt picker and practice timer](https://rick2781.github.io/speaking-practice-prompts/)**

Published by [Articulated](https://articulated.app/), the AI speech-coaching app. Use these communication exercises independently, with a practice partner, or in a group. No account or app is required.

Here, articulation training means organizing and expressing ideas clearly. These exercises focus on communication practice, rather than clinical speech therapy or sound-by-sound pronunciation assessment.

## Start in five minutes

1. Pick a prompt below or open the [practice tool](https://rick2781.github.io/speaking-practice-prompts/).
2. Take about 20 seconds to choose the one point you want to make.
3. Speak aloud for 30 seconds to two minutes. A minute is a useful starting point.
4. Ask yourself: Was my point clear? Did I give an example? Where could I stop sooner?
5. Repeat the same answer, changing just one thing.

Use a comfortable pace. The timer is a practice boundary, not a score. Use invented scenarios whenever you prefer to keep a real experience private.

## Seven-day practice plan

| Day | Practice | Focus |
| --- | --- | --- |
| 1 | Recommend something you enjoy. | Make one clear point. |
| 2 | Explain a familiar technical term. | Replace jargon with an example. |
| 3 | Give a project update. | Lead with the current status. |
| 4 | Disagree with a proposal. | State the shared goal before your concern. |
| 5 | Describe a problem you solved. | Explain what you did and what changed. |
| 6 | Tell a story about a changed plan. | Give it a beginning, a turn, and an ending. |
| 7 | Repeat a prompt from day 1 or day 3. | Notice one change and choose your next focus. |

## Three speaking structures for clearer answers

- **Point → reason → example → point:** Useful for giving an opinion. State your answer, support it, and return to the main idea.
- **Bottom line → context → next step:** Useful for updates. Give the listener the essential information first.
- **Situation → task → action → result:** Useful for experience-based interview questions. Keep your own actions clear.

These are optional scaffolds. Adapt them to the conversation rather than trying to fit every answer into a formula.

## Articulation exercises for adults

Apply one exercise to any prompt in the library. Repeat your answer with the same topic so you can focus on a specific change.

### Make one point

Start with a direct answer in one sentence, give one reason, then add a concrete example. Close by returning to your point. This is useful for impromptu speaking and questions in meetings.

### Replace a vague phrase

Notice one general phrase in your first attempt and make it specific. For example, replace “We need to communicate better” with “Let's send one update every Friday with the decision, owner, and next step.” Try the answer again using your more precise wording.

### Deliver a concise update

Give the status, the detail your listener needs, and the next action. For example: “The draft is ready. We still need the revised figures. Please send them by Thursday so we can review on Friday.” Keep the information your listener needs when you shorten an answer.

## Prompt library

The suggestions under each prompt are possible starting points, not required scripts.

### Everyday conversation practice

1. **Recommend a book, film, or podcast to a friend. Give one reason it is worth their time.**
   - A way in: Recommendation → reason → who it is for.
2. **Explain a hobby to someone who has never tried it. Help them take a first step.**
   - A way in: What it is → why you enjoy it → first step.
3. **Describe a small change that made your day easier. Make the benefit concrete.**
   - A way in: Before → change → after.
4. **Politely turn down an invitation while keeping the relationship warm.**
   - A way in: Appreciation → clear answer → alternative, if you want one.
5. **Explain a familiar technical term without using other technical terms.**
   - A way in: Plain definition → everyday example → why it matters.
6. **Ask for help with a task. Make it clear what you have tried and what you need.**
   - A way in: Goal → what you tried → specific request.

### Professional communication: meetings and updates

1. **Give an update on a project that is on track. End with what happens next.**
   - A way in: Current status → useful detail → next step.
2. **A deadline is at risk. Explain the obstacle and recommend a realistic next step.**
   - A way in: Risk → impact → recommendation.
3. **Disagree with a proposal while showing that you understand its goal.**
   - A way in: Shared goal → concern → alternative.
4. **Ask your team to choose between a faster solution and a more flexible one.**
   - A way in: Decision → tradeoff → your recommendation.
5. **Summarize a long discussion into a decision, an owner, and a next action. Invent a simple scenario.**
   - A way in: Decision → owner → next action.
6. **Explain why a task needs more time without getting lost in its implementation details.**
   - A way in: Outcome → reason → revised plan.

### Interview speaking practice

1. **Introduce yourself for a role you would like. Connect your experience to the work.**
   - A way in: Current focus → relevant experience → what you want next.
2. **Describe a time you solved an unclear problem. Explain your own contribution.**
   - A way in: Situation → task → action → result.
3. **Talk about a mistake and what you changed afterward. Choose an example you are comfortable sharing.**
   - A way in: Mistake → responsibility → change.
4. **Explain how you handled a disagreement with a teammate.**
   - A way in: Difference → conversation → outcome.
5. **Describe something you learned quickly and how you put it into practice.**
   - A way in: Need → learning approach → application.
6. **Answer a question about a skill you have not used yet, honestly and constructively.**
   - A way in: Current experience → related skill → learning plan.

### Storytelling and presentation practice

1. **Tell a short story about a plan that went wrong and what you did next.**
   - A way in: Setup → surprise → response → ending.
2. **Describe a moment when you changed your mind.**
   - A way in: Original view → new information → new view.
3. **Tell someone about a small win that mattered to you.**
   - A way in: Why it mattered → what happened → what you took from it.
4. **Describe the first time you tried something unfamiliar.**
   - A way in: Expectation → experience → discovery.
5. **Tell a story about a helpful piece of advice. Include what you did with it.**
   - A way in: Situation → advice → action → outcome.
6. **Describe a place through one memorable moment rather than a list of features.**
   - A way in: Place → moment → why you remember it.

### Impromptu public speaking practice

1. **Should a team have one meeting-free day each week? Pick a position and acknowledge one tradeoff.**
   - A way in: Point → reason → example → point.
2. **Which everyday skill deserves more attention in school? Explain your choice.**
   - A way in: Choice → reason → practical example.
3. **Is it better to start with a rough draft or a detailed plan? Explain when your answer applies.**
   - A way in: Position → context → example.
4. **If you could improve one part of your neighborhood, what would you choose and why?**
   - A way in: Change → who it helps → first step.
5. **What makes feedback useful? Explain using an invented example.**
   - A way in: Principle → example → takeaway.
6. **Choose an ordinary object and explain what it teaches you about good design.**
   - A way in: Object → observation → lesson.

## About the practice tool

The browser tool includes category filters, a random prompt picker, and a 30-, 60-, 90-, or 120-second timer with pause, resume, and reset. It does not request microphone access, record audio, use cookies, install analytics, or save your answers. GitHub Pages, the hosting provider, may log standard request information.

## Run locally

No dependencies or build step are required. With Python 3 and Node.js installed:

```sh
make check
make serve
```

Open http://localhost:8768. The site lives in `docs/` and is published by GitHub Pages from the `dev` branch. Update the prompt list in `docs/app.js` and the matching text in this README together.
